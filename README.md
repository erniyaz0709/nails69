# Nail 69 · Astana

Одностраничный сайт студии ногтевого сервиса и подологии на React, Vite, Tailwind CSS, Framer Motion и Lucide React.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Фото работ

Четыре переданные фотографии уже находятся в `public/images/`. Массив `worksGallery` в `src/data.js` хранит пути, заголовки и подписи галереи — новые изображения можно добавить туда же и расширить этим массивом.

## Данные студии

Ссылки на WhatsApp, Instagram и 2GIS находятся в `src/data.js`. Список услуг и стоимость сгруппированы по вкладкам в том же файле.
